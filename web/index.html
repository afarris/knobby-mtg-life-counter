Knobby Web Installer

Connect your Knobby device via USB, then click the button below to flash the latest firmware directly from your browser.

Note: This requires a Web Serial compatible browser like Chrome, Edge, or Opera.

Note: If you get an "Installation failed - Your ESP32 board is not supported" error, try flipping your USB cable 180 degrees, refreshing the page, and trying again. The cable orientation affects which chip is exposed for flashing on this device.

Optional: put the audio chip to sleep

The JC3636K518 board has a second chip for Bluetooth audio. Knobby never uses it, but it stays switched on and drains the battery. This button replaces its software with one that keeps it asleep.

  1. Install Knobby with the button above first.
  2. Unplug the USB-C cable from the device, turn the plug over, and plug it back in.
  3. Refresh this page, then click the button below.
  4. Pick the port named "USB Serial" (on Windows, "USB-SERIAL CH340"). If you only see "USB JTAG/serial debug unit", the plug is still the Knobby way up: turn it over again.

Note: This removes the chip's original Bluetooth audio software, and this page cannot put it back. Knobby does not need it.

Note: If no "USB Serial" port appears on Windows, install the CH340 driver, then unplug and replug the cable.

Note: You only need to do this once. Later Knobby updates do not undo it.
